# Finnish Word Search Tool
This project provides an efficient search and suggestion tool for Finnish words using phonetic normalization and Levenshtein distance algorithms.

### Acknowledgments
This project uses the **Sanalista** (Finnish word list) provided by **Kotus** (Institute for the Languages of Finland).

# Suomen kielen sanahakutyökalu
Tämä projekti tarjoaa tehokkaan hakutyökalun suomen kielen sanoille hyödyntäen foneettista normalisointia ja Levenshtein-etäisyysalgoritmia.
